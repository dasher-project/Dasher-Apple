## Settings Cleanup

- [ ] **Duplicate colour theme picker in Customization settings** — Settings shows both a nice colour swatch picker AND a "Color Palette" dropdown parameter. Remove the dropdown; keep the swatch picker. Dasher Font should be a proper font picker (not just text field) plus size slider.
  - **Action**: In `customizationSection`, hide the `SP_COLOUR_PALETTE` param (it's redundant with the swatch picker). Add a native font picker for `SP_DASHER_FONT`. The size slider already exists (`LP_DASHER_FONTSIZE`).
  - **Priority**: Medium
  - **Files**: DasherSettingsView.swift or ContentView.swift (customization section)

## Engine / Platform

- [ ] **TTS rate and pitch controls** — `swift-tts-wrapper` exposes `rate` and `pitch` for AVSpeechSynthesizer. Need to expose these in the Dasher settings UI per-voice, and pass through to the wrapper. Some engines (e.g. offline voices) may not support pitch.
  - **Action**: Add rate/pitch sliders to Speech settings section. Consume from swift-tts-wrapper. Fall back gracefully if engine doesn't support.
  - **Priority**: Medium
  - **Files**: DasherSettingsView.swift (speech section), SpeechService.swift, swift-tts-wrapper package

- [ ] **Input options naming and organization** — Currently only "Stylus" is shown. On iOS we need: Touch, Eyegaze (built-in iPad Pro tracker or hardware), Switch Access (switch control), Keyboard (hardware keyboard), Mouse/Joystick. DasherCore has `LP_INPUT_FILTER` and `SP_INPUT_FILTER` with filter classes (DefaultFilter, OneButtonFilter, TwoButtonDynamicFilter, etc.). The mapping between user-facing names and DasherCore filters needs rethinking.
  - **Action**: Map DasherCore input filters to user-friendly names per platform. iOS: Touch=DefaultFilter, Eyegaze=StylusFilter with eye tracking, Switch=OneButtonFilter/TwoButtonFilter, Keyboard=DefaultFilter+keyboard input. Create platform-specific input filter presets. This is partly a naming/organizational change, partly needs new platform detection code.
  - **Priority**: Medium (important for accessibility compliance)
  - **Files**: Input filter setup in DasherBridge/DasherViewModel, possibly new InputConfiguration.swift
